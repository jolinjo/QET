# QET 圖檔管理 使用教學

> 對象:所有使用 QET 圖檔管理(出庫/入庫/簽核/發行)的同仁。
> 不需要懂 Git——所有操作都在 QET 介面完成。
> 管理員設定見 `pdm-gitea-admin-guide.md`。

---

## 這套系統在做什麼

公司的電氣圖集中放在內網伺服器上,像圖書館:

- 要修改一張圖,先**出庫**(借走並上鎖)——同一時間只有你能改,
  別人會看到「你鎖定中」。
- 改完**入庫**(還回去)——修改推回伺服器,解除鎖定。
- 圖要成為正式版,必須**送審**給確認者看過、核准,再由放行者**發行**。
  發行版有版次編號和 PDF,永遠不會被改掉。

## 初次設定(每人一次)

1. 用瀏覽器開內網 Gitea(網址問管理員),登入你的帳號。
2. 右上頭像 → **設定** → **應用程式** → 產生新 token:
   權限勾 repository(讀寫)、user(唯讀)、organization(唯讀),
   建立後**立刻複製** token(離開頁面就看不到了)。
3. 開 QET → 偏好設定 → **圖檔管理**:
   - Gitea 伺服器:填內網網址(例 `http://hc-server:3000`)
   - Access token:貼上剛複製的 token
   - 本機工作區:保持預設即可
4. 按**驗證連線**,顯示「✓ 連線成功,帳號:你的帳號」就完成了。

之後主視窗左側的**圖檔管理**面板就會列出你能存取的圖庫與圖檔。
(面板被關掉的話,從「檢視」選單把它重新打開。)

## 面板怎麼看

| 狀態欄顯示 | 意思 | 你可以做什麼 |
| --- | --- | --- |
| 可出庫 | 沒人在改 | 出庫並開啟 |
| 編輯中(我) | 你出庫中 | 入庫、取消出庫 |
| 出庫中(+鎖定者名字) | 別人出庫中 | 等待(或請管理員處理卡鎖) |
| 已入庫未送審 | 改好入庫了,還沒送審 | 送審;或再出庫繼續改 |
| 審核中(#N) | 已送審,等確認者 | 確認者:審核檢視/核准/退回 |
| 已確認待發行(#N) | 核准了,等放行 | 放行者:發行 |

隨時可按**重新整理**取得最新狀態。

---

## 製圖者:改一張圖的完整流程

1. **出庫**:在面板選圖 → 按**出庫並開啟**。圖會自動鎖定並在 QET
   開啟,直接編輯、照常存檔(⌘S/Ctrl+S)。
2. **入庫**:改完後在面板按**入庫…**,填寫**變更說明**(必填,
   寫清楚改了什麼,例:「馬達回路加裝熱過載保護,端子表更新」)。
   入庫後鎖定解除,別人就能出庫。
   - 改到一半想先存進度但繼續改?先不要入庫——出庫狀態下你的
     修改只在你電腦上,存檔即可,鎖還是你的。
3. **送審**:狀態變成「已入庫未送審」後按**送審…**,填送審說明
   (確認者會看到)。送審後這張圖會鎖住不能再出庫,直到被退回或發行。
4. **被退回怎麼辦**:狀態回到可出庫,退回意見在 Gitea 的 PR 頁面
   (面板狀態列會提示)。重新出庫 → 修改 → 入庫 → 再送審即可,
   之前的修改紀錄都還在。
5. **想放棄修改**:按**取消出庫**——未入庫的修改會被捨棄、鎖定解除,
   圖回到出庫前的樣子。

## 確認者:簽核

1. 面板裡狀態「審核中(#N)」的圖就是待確認的(自己送審的不能核准)。
2. 按**審核檢視(唯讀)**——QET 會以唯讀模式開啟**送審當下的版本**,
   放大縮小翻頁都可以,就是不能改。
3. 看完後:
   - 沒問題 → 按**核准**。系統會先確認送審內容沒有被偷改過才送出。
   - 有問題 → 按**退回…**,填退回意見(必填,製圖者會看到)。
4. 核准紀錄(誰、何時、核准哪一版)永久保存於 Gitea,可稽核。

> 注意:核准後製圖者若又推了新修改,你的核准會**自動失效**,
> 需要重新審核——這是刻意設計,確保發行的一定是你看過的那一版。

## 放行者:發行

1. 狀態「已確認待發行(#N)」的圖可以發行。
2. 按**發行…**,確認對話框會顯示即將建立的版次(例
   `release/EQ-0001-v3`,版次自動遞增)。
3. 確認後系統自動:合入正式版 → 建立版次 tag → 產生 PDF 附件 →
   清理工作分支。完成後狀態列顯示「已發行」。
4. 發行版在 Gitea 的 Releases 頁面可下載 PDF;圖檔本體任何人
   可用**發行歷史…**選版次以唯讀開啟查看。

## 常見問題

**Q:我要看圖但不用改,需要出庫嗎?**
不用。用**發行歷史…**選最新版次以唯讀開啟即可;還沒發行過的圖,
可以短暫出庫看完後按**取消出庫**(不會留下任何修改)。

**Q:出庫的人休假了,圖被鎖住怎麼辦?**
聯絡管理員依卡鎖流程強制解鎖。不要自己想辦法。

**Q:換電腦/重灌後怎麼辦?**
重做一次「初次設定」即可(token 可以重新產生一個)。原電腦上
未入庫的修改在原電腦的工作區資料夾裡,需要時請管理員協助搬移。

**Q:入庫時說「推送失敗」?**
多半是網路或伺服器暫時不通。你的 commit 已在本機保存,鎖也還是
你的——稍後再按一次**入庫…**(說明隨意填)就會重試推送。

**Q:可以兩個人同時改同一張圖的不同頁嗎?**
不行,鎖定粒度是整個 .qet 檔。需要並行就把設備拆成多個圖檔
(找管理員討論圖檔切割)。
